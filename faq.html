Frequently asked questions

Everything you need to know about getting started with clipBQ.

What is clipBQ?

clipBQ is a cross-platform clipboard manager designed to keep your clipboard history in one place across Linux, macOS, Windows, Android and iOS.

Do I need an account?

Yes. An account allows clipBQ to associate your clipboard history with you and synchronize it across your devices.

Can I use the same account on multiple devices?

Yes. Sign in with the same clipBQ account on each supported device to access your clipboard history.

Does clipBQ automatically save everything I copy?

The desktop client can monitor new clipboard content while running. For mobile releases, users push chosen clips to the app for cloud upload.

Is my clipboard history private?

clipBQ enforces access security via Cloud database Row Level Security. Data is protected with encryption and retention controls.

What happens if I am offline?

This initial version requires a network connection to sync. Desktop updates will queue clipboard changes locally when offline.

Can I delete clipboard items?

Yes, the cloud fully supports clearing history. The interface provides fast, easy methods for deleting entries.

Does clipBQ support images and files?

This release focuses on text clipboard history. Image and file support will follow in future updates.

Why do mobile platforms have different clipboard behaviour?

Android and iOS apply specific privacy restrictions to continuous background clipboard access.

What permissions does clipBQ need?

clipBQ requests minimum permissions required for clipboard monitoring and synchronization based on OS features.

How do I get help?

Once our support channel is ready, links for our documentation, GitHub Discussions, or support email will be added here.
